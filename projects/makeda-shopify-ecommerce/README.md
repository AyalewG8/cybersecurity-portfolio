# MAKEDA — Queen of Sheba Fashion Store

**Project type:** Shopify e-commerce project  
**Live store:** [Visit MAKEDA](https://www-queen-of-hseba.myshopify.com/)

## Overview

MAKEDA is a Shopify fashion storefront for authentic modern and traditional Ethiopian-inspired outfits. This project demonstrates digital-business skills alongside my cybersecurity coursework.

## What It Demonstrates

- Shopify storefront setup and e-commerce design
- Product organization and clear product presentation
- Brand storytelling for a fashion audience
- Customer-journey and mobile-usability considerations
- Practical security awareness for online stores

## Security Awareness

The project highlights security practices important for any e-commerce storefront:

- Protect administrator access with strong passwords and multi-factor authentication
- Give staff only the permissions they need
- Use Shopify's secure checkout capabilities
- Protect customer information and follow clear privacy practices

> This is an e-commerce portfolio project. It is separate from my six cybersecurity coursework projects and does not claim that I built or operated Shopify's payment-security infrastructure.
