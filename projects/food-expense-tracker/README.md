# Simple Food Expense Tracker

**Course:** Programming I  
**Language:** Python  
**Interface:** Console and Tkinter GUI

## Overview

A Python application for recording and organizing food expenses by date, merchant or description, amount, and category. The project began as a console application and was expanded into a desktop GUI.

## Features

- Add, edit, and delete expense records
- Categories for Breakfast, Lunch, Dinner, and Snack
- Persistent JSON data storage
- Input validation for dates, categories, and non-negative amounts
- Search and category filtering
- Table sorting by date, description, category, or amount
- Total spending and category-total summaries
- CSV export of filtered records

## Technologies

Python · Tkinter · JSON · CSV · File input/output · Functions · Lists · Dictionaries · Loops · Conditionals

## Run the GUI

```bash
python food_expense_tracker_gui.py
```

Python 3 with Tkinter is required. The application creates and uses `expenses.json` in the same folder to store expense records.

## Project Files

- `food_expense_tracker_gui.py` — enhanced desktop GUI application
- `food_expense_tracker_console.py` — original console-based version
