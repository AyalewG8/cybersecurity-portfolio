# Enterprise Security Risk Management Program Development

## Course
ISEC1373 — Security Risk Management

## Scenario
GlobalTech Solutions is a growing technology company with a hybrid workforce, cloud services, customer-facing applications, and multiple locations.

## Project Purpose
This project applies cybersecurity risk management methods to identify, assess, prioritize, and treat organizational security risks.

## Main Deliverables
- Organizational profile
- Asset inventory
- Threat-vulnerability analysis
- Risk register
- Risk prioritization
- Risk treatment plan
- Governance and compliance review
- 12-month implementation roadmap
- Executive summary

## Key Risks Identified
- Ransomware
- Phishing
- Data breach
- Cloud misconfiguration
- Insider threats
- Distributed denial-of-service attacks
- Unpatched systems
- Lost or stolen devices
- Third-party compromise
- Power or service interruption

## Recommended Controls
- Multifactor authentication
- Endpoint detection and response
- Security information and event management
- Tested backups
- Patch management
- Encryption
- Least privilege
- Security awareness training
- Incident response planning
- Cyber insurance

## Frameworks Referenced
- NIST Cybersecurity Framework
- ISO/IEC 27001
- CIS Critical Security Controls
