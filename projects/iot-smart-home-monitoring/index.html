Project 06 · IoT Security & Monitoring

IoT Smart Home Monitoring System

A sensor-based monitoring prototype using Raspberry Pi, environmental sensors, MQTT over TLS, cloud dashboards, local buffering, and threshold alerts.

Objective

Collect environmental telemetry reliably, protect data in transit, maintain visibility during connectivity problems, and turn sensor readings into useful dashboards and alerts.

My Role

Designed the concept, selected hardware and software components, and focused on secure telemetry, resilience, monitoring visibility, and alerting.

Performance Targets

95% sensor accuracy target · 10-second dashboard refresh · 95%+ uptime · threshold-based alerts

Outcome & Key Learning

MQTT fits low-bandwidth IoT environments well, but reliable deployments also require sensor calibration, encrypted transport, authentication, offline buffering, and network resilience.
