Project 06 · IoT Security & Monitoring

IoT Smart Home Monitoring System

Sensor-based monitoring prototype using Raspberry Pi, DHT22 and MQ135 sensors, MQTT over TLS, cloud dashboards, local buffering, and threshold alerts.

Monitoring Flow

Sensors → Raspberry Pi → MQTT over TLS → Cloud Broker → Time-Series Data → Dashboard → Alerts ↘ Local Buffer for offline resilience

Performance Targets

95% sensor accuracy target · 10-second dashboard refresh · 95%+ uptime · threshold-based alerts

My Role

Designed the concept, selected hardware/software components, and focused on reliable telemetry, visibility, resilience, and secure communication.

Technology

Raspberry Pi 4BDHT22MQ135MQTTTLSAWS IoT / Blynk ConceptsTime-Series DataAlerts

Key Learning

MQTT is well suited to low-bandwidth IoT environments, but sensor calibration, encrypted transport, offline buffering, authentication, and network resilience are essential for dependable deployments.
