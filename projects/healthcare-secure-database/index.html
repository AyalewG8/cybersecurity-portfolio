Project 03 · Database Security

Healthcare Clinic Secure Database

A normalized PostgreSQL healthcare data model designed to preserve confidentiality, integrity, and availability of protected health information.

Core Entities

Patients · Visits · Users

Security Focus

RBAC · Least privilege · MFA concept · Encryption · Audit logging · Backup/DR

Secure Data Flow

Clinicians → MFA login → Application / API Application / API → TLS + validation → RBAC RBAC → Patients / Visits / Users All activity → Audit Log Database → Backup + Disaster Recovery

Controls

PostgreSQLRBACLeast PrivilegeTLSEncryption at RestAudit LogsIntegrity ConstraintsHIPAA-Aware Design

Key Learning

Secure database design extends beyond tables and relationships. Identity, access, encryption, logging, validation, and recovery controls must work together.
