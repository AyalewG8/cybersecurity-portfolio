RetailHub OWASP Web Assessment

An OWASP-focused review of a fictional e-commerce application, translating technical weaknesses into prioritized remediation and blue-team actions.

Objective

Identify high-impact web application risks, connect them to business consequences, and recommend practical controls that reduce account takeover, data exposure, and application abuse.

Reviewed authentication, authorization, input handling, encryption, logging, and API controls; ranked findings by risk; and documented remediation priorities.

Outcome & Key Learning
