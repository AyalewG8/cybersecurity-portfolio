Project 02 · Cryptography & Network Security

SecureHealth Cryptography & Network Security

Protected-health-information architecture designed to secure EHR systems, cloud services, and partner connections while supporting HIPAA/HITECH-aligned safeguards.

Security Goals

Confidentiality · Integrity · Authenticity · Non-repudiation

Threats Addressed

Eavesdropping · MITM · Ransomware · Insider threats · Denial-of-service

Cryptographic Controls

TLS 1.3AES-256-GCMECDSA P-256ECDH / PFSSHA-256HMAC-SHA-256

Key Management

Three-tier PKI with an offline Root CA, online Intermediate CA, FIPS 140-3 HSM protection, certificate revocation, CRL, and OCSP support.

Trust Flow

Patient Portal → TLS 1.3 → DMZ / WAF → EHR Partner Hospital → IPsec VPN + mTLS → EHR EHR → AES-256 protected data → HSM-backed key management Audit events → signed logs → monitoring

Key Learning

Strong algorithms are only one part of cryptographic security. Key generation, storage, rotation, revocation, and lifecycle discipline make protection effective.
