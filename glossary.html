Project Glossary

Plain-language definitions for the cybersecurity, programming, IoT, database, and e-commerce terms used throughout this portfolio.

01 Risk02 Cryptography03 Database04 Web Security05 Vulnerability06 IoT07 Python08 Shopify

01 · Northbridge Logistics Risk Assessment

NIST SP 800-30National Institute of Standards and Technology guidance for identifying and evaluating information-security risk.
Risk AssessmentA structured review of threats, vulnerabilities, likelihood, and business impact.
CVSSCommon Vulnerability Scoring System; a standard way to describe the technical severity of a vulnerability.
MITRE ATT&CKA knowledge base that organizes attacker behaviors, tactics, and techniques.
MFAMulti-Factor Authentication; verifies identity with two or more types of evidence.
EDREndpoint Detection and Response; monitors computers and helps detect, investigate, and contain threats.
SIEMSecurity Information and Event Management; collects and analyzes security logs in one place.

02 · SecureHealth Cryptography & Network Security

AES-256-GCMStrong symmetric encryption that protects data confidentiality and verifies that data was not changed.
TLS 1.3Transport Layer Security; protects data moving between systems over a network.
PKIPublic Key Infrastructure; manages digital certificates and public/private encryption keys.
ECDHElliptic Curve Diffie–Hellman; a method for securely agreeing on a shared secret.
HSMHardware Security Module; a protected device used to create, store, and use cryptographic keys.
IPsecInternet Protocol Security; protects network traffic at the IP layer, often in a VPN.
HIPAA / HITECHU.S. laws and rules that establish protections and accountability for health information.

03 · Healthcare Clinic Secure Database

PostgreSQLAn open-source relational database management system.
SQLStructured Query Language; used to create, read, update, and manage relational data.
RBACRole-Based Access Control; grants permissions according to a person's job role.
PHIProtected Health Information; identifiable health information protected by HIPAA.
3NFThird Normal Form; a database design method that reduces duplication and update problems.
ERDEntity-Relationship Diagram; a visual map of database tables and their relationships.
ACIDAtomicity, Consistency, Isolation, and Durability; properties that support reliable database transactions.

04 · RetailHub Web Application Security Assessment

OWASP Top 10An awareness list of major web-application security risks.
XSSCross-Site Scripting; unsafe script code is injected into pages viewed by other users.
InjectionUntrusted input changes a command or query in an unintended way.
WAFWeb Application Firewall; filters web traffic to help block malicious requests.
SAST / DASTStatic and Dynamic Application Security Testing; examines source code or tests a running application.
OAuth 2.0A framework that lets an application receive limited access without sharing a user's password.
APIApplication Programming Interface; rules that allow software systems to exchange data and functions.

05 · ABC Logistics Threat & Vulnerability Management

VulnerabilityA weakness that could be exploited to harm a system or its data.
ThreatA person, event, or condition capable of causing harm.
ExploitabilityHow practical or likely it is for an attacker to use a vulnerability.
Asset CriticalityThe importance of a system or resource to business operations.
RemediationCorrecting or reducing a vulnerability through patches, configuration, controls, or replacement.
Re-scanScanning again after a fix to verify that the vulnerability is no longer present.

06 · IoT Smart Home Monitoring System

IoTInternet of Things; connected physical devices that collect, process, or exchange data.
Raspberry PiA small single-board computer used for learning, prototyping, and embedded projects.
MQTTA lightweight publish/subscribe messaging protocol commonly used by IoT devices.
GPIOGeneral-Purpose Input/Output; pins used to connect a computer board to sensors and other hardware.
TelemetryMeasurements automatically collected and sent from a remote device.
Local BufferingTemporarily storing data on the device when the network or cloud service is unavailable.

07 · Food Expense Tracker

PythonA general-purpose programming language used for scripting, automation, data work, and applications.
TkinterPython's standard interface for creating desktop graphical user interfaces.
JSONJavaScript Object Notation; a text format for storing and exchanging structured data.
CSVComma-Separated Values; a simple tabular text-file format.
Input ValidationChecking user entries before accepting or processing them.
CRUDCreate, Read, Update, and Delete; four basic operations performed on stored records.

08 · MAKEDA — Queen of Sheba

E-CommerceBuying and selling products or services through digital systems.
ShopifyA hosted platform for building and managing online stores.
Least PrivilegeGiving each user only the access needed to perform assigned work.
Secure CheckoutA protected transaction process that encrypts data and uses trusted payment handling.
Customer JourneyThe steps a customer takes from discovering a product through purchase and follow-up.
Data PrivacyResponsible collection, use, storage, and protection of personal information.
